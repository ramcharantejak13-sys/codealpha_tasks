# Task 2: Unemployment Analysis with Python

## Objective
Explore unemployment data, clean column names and missing values, examine time and regional patterns, and create visualizations.

## Dataset
Download the CSV from:
https://www.kaggle.com/datasets/gokulrajkmv/unemployment-in-india

Save it as `data/unemployment.csv`.

## Run
From the pack root:
```bash
pip install -r requirements.txt
python Task2_Unemployment_Analysis/unemployment_analysis.py
```

## Outputs
- `outputs/unemployment_over_time.png`
- `outputs/top_regions_average_unemployment.png`
- `outputs/unemployment_cleaned.csv`
- `outputs/summary.txt`

## Notes
The dataset's exact column labels can differ by copy. The script normalizes common variants. Read the charts and summary generated from your actual dataset before stating conclusions.
